# FaceAttendance —— iPhone 人脸识别考勤系统

在 iPhone 上独立运行的课堂点名应用：新建课程 → 导入花名册（Excel，含证件照）→ 打开相机实时扫视全班 → 人脸头顶实时标注姓名（绿=已确认 / 橙=待确认 / 红=未识别）→ 完成签到导出 Excel，历次记录永久保存、互不覆盖、可随时分享下载。

- **完全离线**：人脸检测（SCRFD，含五点关键点）+ 人脸识别（ResNet50，InsightFace buffalo_l 同款）都以 Core ML 形式在本机运行，不需要网络、不需要服务器。
- 详细工程文档（环境要求、Xcode 建工程步骤、依赖、常见问题）见 [FaceAttendance/README.md](FaceAttendance/README.md)。

## 核心功能

- **实时扫描签到**：4K 相机采集 + SCRFD 检测 + ResNet50 识别 + IoU 跨帧跟踪多帧融合，头顶实时标注确认状态
- **照片签到**：从相册导入全班合影（支持多张照片、EXIF 时间），识别后人工修正再导出
- **个人签到**：前置相机单人快速签到（640² 快检模型，速度 ×9），支持手动补签兜底
- **随机点名 / 随机数**：均匀抽取学生展示头像学号；输入 n 生成 1~n 随机数，可反复生成
- **点击改判**：扫描中随时点按人脸标签纠正识别结果，自动写回
- **Excel 导入导出**：花名册解析（照片锚点 → 学号/姓名/班级）、考勤表一键导出、历史记录永久保存互不覆盖

## 使用方法

### 1. 安装（一次性，约 5 分钟）

- 需要：Mac + Xcode 15+、iPhone（iOS 16+，必须真机）、免费 Apple 个人开发者账号
- Xcode 打开 `FaceAttendance/FaceAttendance.xcodeproj`，选 Team 后真机运行即可

### 2. 点名流程

1. 打开 App → **新建课程**（如“数学分析”）
2. **导入花名册**：选择 Excel 文件（格式：学号 / 姓名 / 班级 + 证件照，示例见 `FaceAttendance/Resources/示例花名册_33310019.xlsx`），照片自动提取为人脸底库
3. **开始签到**：
   - 实时扫描：相机扫视全班，头顶实时标注姓名；对存疑者点按标签改判
   - 或照片签到：课后导入全班合影，识别后统一修正
4. **完成导出**：一键生成 Excel 考勤表并分享；历史记录随时回看

### 3. 存档

`FaceAttendance_iOS源码_v*.tar.gz` 为历次源码归档，最新为 **v6.9.0**（2026-10-09）。
